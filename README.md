# 자린고비 · 그룹 굴비 (복제본)

원래 자린고비 앱(https://github.com/dusend03/jaringobi)을 복제해서 여러 기능을 더한 버전이에요.

## 더한 기능

1. **빵빠레** — 오늘 아낀 금액이 하루 목표(아낄 소비 금액의 합)의 5배 이상이 되면 하루 한 번 빵빠레가 터져요.
   예: ‘커피 안 사기 · 3,000원’이면 오늘 15,000원 이상 아꼈을 때.
2. **그룹 굴비** — 아래 탭에서 ‘그룹 굴비’로 가면 친구들과 공동 목표를 함께 모아요.
   - 그룹 만들기 / 발표용 예시 그룹
   - 친구 초대 (초대 링크 복사, 이름으로 추가)
   - 공동 목표 설정·수정 (이름, 금액, 사진)
   - 콕 찌르기 (오늘 아직 안 아낀 친구에게)

3. **응원 목소리** — ‘아꼈어’를 누르면 “뿅” 소리와 함께 응원 목소리가 나와요. ‘못 아꼈어’, 빵빠레, 목표 달성 때도 각각 다른 대사가 나와요. ‘수정’ 화면의 ‘소리’에서 끌 수 있어요.
4. **몇 번 남았는지 계산** — 홈에서 ‘목표 가격 ÷ 하루 목표 = 몇 번 참으면 되는지’와 남은 횟수를 보여줘요. 아낄 소비가 여러 개면 ‘일’ 단위로 보여줘요.
5. ~~오늘 빵빠레 게이지~~ — 화면이 복잡해서 사용자에게는 보이지 않게 뺐어요. 빵빠레는 그대로 터져요.
6. **굴비가 걸리는 효과** — 사진을 올려 굴비를 걸면 홈에서 사진이 위에서 떨어지며 걸리고, 그 뒤로 살랑살랑 흔들려요.
7. **목표 달성 → 사기 전에 두 가지 질문** — 모은 금액이 목표를 넘는 순간 금액이 차오르며 ‘달성!’ 도장과 색종이가 터져요. 이어서 두 가지를 물어요. ① “처음 걸어뒀을 때만큼, 지금도 갖고 싶나요?” ② (갖고 싶다고 하면) “이걸 위해 모은 돈과 기다린 시간을 생각해도, 사고 싶은가요?” 어떤 답을 골라도 먼저 모은 돈을 칭찬해요. 그래도 산다면 그 선택을 인정하고, 안 사거나 마음이 바뀌어도 칭찬하며 다음 굴비로 이어 줘요. 참았으니 사지 말라는 앱이 아니라, 충분히 생각하고 사도록 돕는 앱이니까요.
8. **쿠팡에서 사러 가기** — ‘그래도 산다’를 고르면 쿠팡으로 가는 버튼이 나와요. 굴비 달기에서 ‘물건 이름’을 적으면 그 이름으로 쿠팡을 검색하고, 발표용 예시는 소니 WH-1000XM5 검색 결과로 가요. 목표에 쿠팡 파트너스 링크(`link.coupang.com/…`)를 넣으면 그 링크로 가고, 법적으로 필요한 파트너스 고지 문구가 함께 나와요.
   - **발표용 버튼:** 홈 맨 아래 ‘쿠팡 파트너스 (발표용)’을 누르면, 다 모은 것처럼 두 질문 → ‘그래도 산다’ → ‘쿠팡에서 사러 가기’와 파트너스 고지 문구까지 바로 보여 줘요. 실제 기록은 바뀌지 않아요.
9. **적금 추천 배너** — 홈 맨 아래에 금융감독원 파인(FINE) ‘금융상품한눈에’에 공시된 은행 적금 중 12개월 최고 금리가 높은 5개를 5초마다 바꿔 보여줘요. 누르면 금융상품한눈에로 가요.
   - `api/savings.js`가 앱을 열 때마다 금감원 오픈 API를 실시간으로 불러요. 금감원 약관상 받은 정보를 저장하면 안 되고, 화면에 ‘금융상품통합비교공시시스템(금융감독원) 금융회사 상품정보’라고 출처를 적어야 해요.
   - 금감원 오픈 API 인증키(https://finlife.fss.or.kr 에서 무료 신청)를 Vercel 프로젝트 → Settings → Environment Variables에 `FSS_API_KEY`라는 이름으로 넣어야 실제 상품이 나와요. 키를 코드에 직접 적지 마세요.
   - 키가 없거나 불러오지 못하면 ‘예시’라고 적힌 배너가 나와요.

목소리는 `voices/` 폴더의 녹음 파일이에요. AI 가상 성우 서비스 타입캐스트(https://typecast.ai)의 ‘다은’ 목소리로 만들었고, 무료 플랜 조건(비상업적 사용 · 출처 표기)에 따라 ‘수정’ 화면에 출처를 적어 두었어요.

## 안드로이드 앱 (APK)

- 받기: https://github.com/dusend03/jaringobi-group/releases/download/apk-latest/jaringobi.apk
- 앱은 https://jaringobi-group.vercel.app 을 그대로 보여 주는 껍데기예요. 웹을 고치면 앱도 따로 다시 만들 필요 없이 바로 바뀌어요.
- 설치할 때 ‘출처를 알 수 없는 앱 설치’를 허용해야 해요. 아이폰은 APK를 설치할 수 없으니 웹 주소를 쓰세요.
- APK를 새로 만들려면 GitHub의 Actions 탭 → ‘APK 만들기’ → Run workflow를 누르면 돼요. (`.github/workflows/apk.yml`)
- 쿠팡·금감원 링크는 앱 밖의 브라우저에서 열려요.

## 알아둘 점

그룹 기능은 **발표용 시연**이에요. 친구와 친구가 모은 금액은 이 기기 안에서만 만들어진 예시라서, 실제 다른 사람에게 초대나 콕 찌르기가 전달되지는 않아요.
초대 링크를 열면 같은 이름과 목표 금액의 그룹에 들어간 모습을 보여줘요. 콕 찌른 친구는 잠시 뒤 아낀 것으로 응답해요.

기록은 각자의 브라우저에 저장되고, 로그인 화면은 실제 계정을 확인하지 않아요.

## 수정하는 법

GitHub에서 `index.html`을 열고 연필(✏️) 버튼으로 고친 뒤 **Commit changes**를 누르면 1분 안에 배포 주소에 반영돼요.

- 발표용 예시 그룹 바꾸기: `sampleGroup` 부분의 그룹 이름, 목표 금액, 친구 이름과 금액을 고치면 돼요.
- 빵빠레 기준 바꾸기: `checkFanfare` 안의 `goal * 5`에서 5를 바꾸면 돼요.
