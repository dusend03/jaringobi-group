# 자린고비 · 그룹 굴비 (복제본)

원래 자린고비 앱(https://github.com/dusend03/jaringobi)을 복제해서 두 가지를 더한 버전이에요.

## 더한 기능

1. **빵빠레** — 오늘 아낀 금액이 하루 목표(아낄 소비 금액의 합)의 5배 이상이 되면 하루 한 번 빵빠레가 터져요.
   예: ‘커피 안 사기 · 3,000원’이면 오늘 15,000원 이상 아꼈을 때.
2. **그룹 굴비** — 아래 탭에서 ‘그룹 굴비’로 가면 친구들과 공동 목표를 함께 모아요.
   - 그룹 만들기 / 발표용 예시 그룹
   - 친구 초대 (초대 링크 복사, 이름으로 추가)
   - 공동 목표 설정·수정 (이름, 금액, 사진)
   - 콕 찌르기 (오늘 아직 안 아낀 친구에게)

## 알아둘 점

그룹 기능은 **발표용 시연**이에요. 친구와 친구가 모은 금액은 이 기기 안에서만 만들어진 예시라서, 실제 다른 사람에게 초대나 콕 찌르기가 전달되지는 않아요.
초대 링크를 열면 같은 이름과 목표 금액의 그룹에 들어간 모습을 보여줘요. 콕 찌른 친구는 잠시 뒤 아낀 것으로 응답해요.

기록은 각자의 브라우저에 저장되고, 로그인 화면은 실제 계정을 확인하지 않아요.

## 수정하는 법

GitHub에서 `index.html`을 열고 연필(✏️) 버튼으로 고친 뒤 **Commit changes**를 누르면 1분 안에 배포 주소에 반영돼요.

- 발표용 예시 그룹 바꾸기: `sampleGroup` 부분의 그룹 이름, 목표 금액, 친구 이름과 금액을 고치면 돼요.
- 빵빠레 기준 바꾸기: `checkFanfare` 안의 `goal * 5`에서 5를 바꾸면 돼요.
